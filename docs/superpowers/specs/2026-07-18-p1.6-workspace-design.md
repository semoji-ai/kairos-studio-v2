# Kairos Studio v2 — P1.6: 작업 폴더(workspace) 연결 설계

날짜: 2026-07-18
상태: 승인됨 (사용자 확인)

## 목적

publish_agent(semoji-ai/publish_agent — Claude Code 스킬 시스템) 등 스킬 기반
워크스페이스를 스튜디오 채팅에서 그대로 쓰게 한다. 방식: CLI subprocess의
**cwd를 설정 가능한 workspace_dir로** 실행 — claude CLI가 해당 폴더의
`.claude/skills`·`CLAUDE.md`를 자동 로드하므로 별도 통합 코드가 불필요.

## 변경

### settings (core/settings.py)
- 키 추가: `"workspace_dir": None` (기본 null = 기존처럼 cwd 미지정)
- 검증: null 또는 str. str이면 `Path(v).expanduser().is_dir()`여야 함 — 아니면
  ValueError("workspace_dir does not exist"). (PUT 400)

### providers (core/providers/{claude,codex}.py)
- `chat(..., cfg)`에서 `cwd = cfg.get("workspace_dir")` — truthy면
  `subprocess.Popen(..., cwd=expanduser(cwd))`. null/미지정이면 기존 그대로(cwd 없음).

### server (core/server.py)
- 변경 불요(cfg는 이미 chat에 전달됨). PUT /settings 검증은 settings._validate가 담당.
- `GET /workspace/info` (authed) 추가:
  `{workspace_dir, exists, skills: [이름...], has_claude_md: bool}`
  - skills: `{workspace}/.claude/skills/*/`와 `{workspace}/skills/*/SKILL.md`(publish_agent
    루트 구조) 디렉토리명 목록. workspace_dir null이면 빈 목록 + exists=null.

### UI (app/src/Settings.tsx, api.ts)
- 저장소 섹션에 "작업 폴더" 입력 + 저장(putSettings {workspace_dir}) — 빈 문자열
  저장 시 null로 변환(연결 해제).
- 저장 후 workspaceInfo() 호출해 "스킬 N개 감지: publish-write, ..." 안내 표시.
- 워크스페이스가 설정돼 있고 claude_permission_mode가 "default"면 안내문:
  "스킬이 파일을 쓰려면 권한을 acceptEdits/workspace-write로 올리는 것을 권장" —
  자동 변경은 하지 않음.

## 완료 기준
1. 설정에서 작업 폴더 지정(존재 검증) → 이후 채팅의 CLI가 그 폴더에서 실행됨
   (fake argv/cwd 덤프로 검증)
2. 미존재 경로는 400, 설정 유지
3. /workspace/info가 publish_agent 클론 폴더에서 스킬 목록을 반환
4. UI에 스킬 감지·권한 권장 안내 표시 (GUI는 수동 확인 대기)

## 제외 (YAGNI)
- 스킬 실행 버튼 UI, 리포 병합, 권한 자동 변경, church 브랜치 관리
